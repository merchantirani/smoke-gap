# Play Store Assets - pause app

## 📱 How to Take Screenshots (Full Screen Mobile)

### Method 1: Browser Full Screen (Recommended)
1. Open HTML file in Chrome
2. Press `F11` for full screen
3. Press `Ctrl + Shift + M` (DevTools)
4. Select iPhone 14 Pro (393x852)
5. Click screenshot icon 📷
6. Save as PNG

### Method 2: Phone Browser
1. Transfer HTML file to phone
2. Open in Chrome/Safari
3. Take native screenshot
4. Crop to remove browser UI

### Method 3: Use Actual App
1. Install app on phone
2. Navigate to each screen
3. Take screenshot
4. This is BEST for Play Store

## 🎯 Screenshot Requirements

**Play Store requires:**
- Minimum 2 screenshots
- Maximum 8 screenshots
- Aspect ratio: 16:9 or 9:16
- Resolution: 320px - 3840px
- Format: PNG or JPEG
- File size: Max 15MB each

**Recommended sizes:**
- Phone: 1080 x 1920 (9:16)
- Tablet: 1200 x 1920 (optional)
